# Exploring Generative AI and AI Fundamentals

## 1. Introduction
Generative AI refers to artificial intelligence systems that can generate new content based on user input and learned patterns. Modern generative models can create text, images, code and other forms of content.

## 2. Selected Generative AI Model: GPT
For this project, GPT was selected as the generative model. GPT is a language model designed to understand text input and generate relevant natural-language output.

## 3. Use Cases
GPT can be applied to question answering, summarization, content generation, education, customer support, brainstorming and text transformation.

## 4. Application Developed
A simple GPT Study Assistant was developed using Python and Streamlit. A user enters a question in the web interface, and the application sends the input to GPT through the OpenAI API. The generated response is then displayed to the user.

## 5. Prompt Engineering
The application uses instructions that tell GPT to behave as a study assistant and provide clear, accurate and beginner-friendly answers. This demonstrates how instructions can influence the style and usefulness of generated output.

## 6. Technologies
Python, Streamlit, OpenAI API, GPT and GitHub were used.

## 7. Evaluation
The application can be evaluated by testing questions from different topics and checking whether the responses are relevant, understandable and useful. Users should also verify important factual information because generative AI can sometimes produce incorrect information.

## 8. Conclusion
The project provides a simple practical demonstration of Generative AI. It shows how a GPT model can be connected to a Python application through an API and used to create an interactive study assistant.
